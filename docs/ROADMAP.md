# Roadmap

## v0.2.x

- Tune tournament prompts.
- Improve parsing of judge responses.
- Add optional JSON run export.
- Add a short config guide for changing models.
- Add lightweight tests for parsing and ranking.

## v0.3.0

- Persistent run history.
- Optional memory across runs.
- Better final synthesis from multiple top ideas.
- Configurable generation count and survivor count from the command line.

## v0.4.0

- Specialized agent roles.
- Debate rounds where models respond to each other.
- Role-specific prompts for Skeptic, Engineer, Researcher, Synthesizer, and Optimizer.

## Later

- Local UI for reviewing council runs.
- Visual idea lineage graph.
- Benchmark prompts for comparing Synapse versions.
- More robust model availability diagnostics.
